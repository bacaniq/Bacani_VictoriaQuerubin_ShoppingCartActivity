# AI Usage in this Project
1. Which parts of the project you used AI for (if any)
- **Debugging:** Some parts of my code, especially the part where the system checks for existing products, I used AI to know how to properly code that function. Not only the existing product there are other parts of the code I used for debugging.
- **Logic Structuring:** I used AI for me to make a more clean and structured code, in order for me not to get confused when adding a new set of functions.
- **Tutorial on how to create a commit in github:** First time working with github, since I’m not familiar with the commit things I asked AI for help.
- **Try.Parse:** This part is unfamiliar to my understanding, that’s why I used AI to help me understand how that works.


2. Why you used AI in those parts 
- I used AI as a guide to better understand the relationship between functions, methods, and classes. Instead of just getting the project done, I wanted to ensure my code was clean, structured, and followed best practices. I made it a point not to copy-paste the AI's suggestions; instead, I manually typed the code to understand it better. I realized that by typing it out myself, I was able to trace the logic and actually learn how each line works, which helped me identify and fix errors more effectively.
